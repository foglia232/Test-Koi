# 恋爱回应图鉴

双击 `index.html` 就能在浏览器里打开，不需要安装任何东西。答题进度和结果只保存在当前浏览器里。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `assets/questions.js` | 全部题目和选项（32—33 题） |
| `assets/types.js` | 16 种类型的完整文案，以及四个习惯的说明 |
| `assets/report.js` | 关系判断、他的表现、想念 / 新的人 / 态度、接下来、心理学小知识、交叉解读 |
| `assets/config.js` | 分界线设置（见下文） |
| `assets/engine.js` | 计分和判断规则 |
| `assets/art.js` | 16 种类型 × 从容态 / 牵动态的插画 |
| `assets/app.js`、`assets/style.css` | 页面流程和样式 |

改文案只需要改 `types.js`、`report.js`、`questions.js` 里的文字。

## 题目结构

| 部分 | 题数 | 用途 |
| --- | --- | --- |
| 先说说你们 | 4 | 关系阶段、持续多久、最近交流次数、有没有“不联系”的约定 |
| 你喜欢一个人的时候 | 12 | 四个习惯各 3 题，决定 16 种类型 |
| 这一个月的你 | 4 | 决定从容态 / 牵动态 |
| 这一个月的他 | 8 | 主动联系、说到做到、谈关系、尊重与安全感，各 2 题 |
| 你心里的那几个问题 | 4—5 | 想念（及之后发生了什么）、新的人、他的态度、你最想要的答案 |

### 为什么类型题是每个习惯 3 题

用模拟作答测过：每个习惯 3 题和 4 题，重测时得到同一结果的比例只差 2—3 个百分点。分布是否均匀，主要取决于每道题两边的选项是否同样有吸引力，所以每道题都配了两个偏向一端、两个偏向另一端的选项，并且打乱顺序。3 题还有一个好处：不会出现两边平票，原来的 4 道“平分补充题”可以去掉。

模拟结果（4 万次）：16 种类型各占 6.0%—6.6%；32 种组合全部出现。

### 上线后可以调的两条分界线（`config.js`）

- `axisCut`：如果真实用户明显偏向某一边（比如大多数人都是“等待回应”），把对应维度调低一点（例如 1.75），不需要改题目。
- `stateCut`：处在关系危机中的人，大约八成会被判为“牵动态”。这符合真实情况。如果想让两种状态更平均，可以调到 2.25 左右。

建议先收集一两百份真实结果，再决定要不要调整。

## 部署到 Netlify

1. 打开 app.netlify.com/drop
2. 把整个 `love-test` 文件夹拖进去，就会得到一个网址

页面加了 `noindex`，不会被搜索引擎收录。需要注意：网址本身没有门槛，拿到链接的人都能做，也能继续转发给别人。如果之后想防转发，可以改成每个购买者一个专属链接，并在服务端校验。

## 换成画师的插画

所有插画都由 `Art.type(art, state)` 生成。拿到正式插画后，把它换成 `<img src="images/${art}-${state}.png">` 即可，文件名用 `types.js` 里每种类型的 `art` 字段（例如 `candle-T.png`）。
